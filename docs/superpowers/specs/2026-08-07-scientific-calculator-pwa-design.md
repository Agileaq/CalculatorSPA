# 科学计算器 PWA — 设计文档

- 日期：2026-08-07
- 状态：已通过设计评审，待用户审阅 spec
- 范围级别：**方案 B**（常规科学计算器：外观 1:1 + 大部分功能真实可用；不做自然分数显示与 MATH 二维结构编辑）

## 1. 目标与背景

按提供的截图（类 Casio fx 自然显示科学计算器）实现一个**单页面应用**，要求：

- 纯浏览器执行，**离线可运行**
- 部署为 **GitHub Pages** 静态站点
- 可作为**手机端 PWA** 安装（添加到主屏幕，独立窗口运行）

## 3. 架构

### 3.1 技术栈

纯静态、零依赖、零构建。HTML + CSS + 原生 JavaScript（ES modules）。GitHub Pages 直接托管。

### 3.2 文件结构

```
CalculatorSPA/
├── index.html            # 结构骨架 + 引入
├── styles.css            # 全部样式（深色主题、按钮网格、显示区）
├── js/
│   ├── app.js            # 入口：绑定按钮/键盘事件，协调各模块
│   ├── tokens.js         # 算式模型：token 列表 + 光标位置（增删改 + undo/redo）
│   ├── lexer.js          # 把 token 列表转成可求值的记号流
│   ├── parser.js         # 递归下降解析 → AST（优先级/括号/一元函数/隐式乘法）
│   ├── evaluator.js      # 求值 AST，含 DEG/RAD、Ans、变量、错误抛出
│   ├── formatter.js      # 显示格式化（12 位有效数字、去毛刺、科学计数）
│   ├── history.js        # 历史记录 + STO 变量，localStorage 持久化
│   └── state.js          # 全局状态（角度模式、Shift 状态、Ans）
├── manifest.webmanifest  # PWA 清单
├── sw.js                 # service worker，离线缓存
├── icons/                # PWA 图标（192×192、512×512）
└── README.md             # 部署说明
```

### 3.3 分层思路

- `tokens.js`：只负责「用户在编辑什么」——光标 + token 列表，驱动显示。
- `parser + evaluator`：只负责「这串东西等于几」。

两者解耦：编辑逻辑改动不影响求值；求值引擎（纯函数）可独立测试。

### 3.4 数据流

按钮 / 键盘事件 → 修改 token 模型 → 重渲染显示区 → 按 `=` 时把 token 流交给 `lexer → parser → evaluator` → 结果经 `formatter` 显示 → 成功则存入 `history`。

## 4. 按钮功能映射

实现状态：✅ 真实现 / ⛔ 占位（可见、样式一致；**点击时弹出短暂非阻塞提示** ——见 5.6 占位提示）。

### 顶部徽标区
- `CAL` / `RAD` 徽标 → ✅ 点击切换 DEG/RAD，实时显示当前模式（默认 `DEG`）

### 功能行第 1 排
- `Shift ↑` → ✅ 第二功能态（徽标提示，影响带上标的键）
- `↷` 重做 / `↶` 撤销 → ✅ 对 token 编辑做 undo/redo 栈
- `∧` 上 → ⛔（MATH 二维导航）
- `⌫` 退格 → ✅ 删光标前一个 token

### 功能行第 2 排
- `AC` → ✅ 清空当前算式
- `<` `>` → ✅ 光标左右移动
- `MATH` → ⛔（结构化编辑入口）
- `↺` 历史 → ✅ 打开历史面板，点条目回填算式

### 功能行第 3 排
- `FXs` 自定义函数 / `GRP` 分组 → ⛔
- `∨` 下 → ⛔
- `, ,` 分隔 → ⛔
- `STO` → ✅ 把当前结果/值存入变量（A–F 等）

### 科学函数区
- `π` ✅ | `Ln` ✅ | `Sin` `Cos` `Tan` ✅（受 DEG/RAD 影响）
- `X` → 作为变量名输入（配合 STO）
- `X²` ✅ | `√` ✅ | `(` `)` ✅

### 数字键盘区
- `7 8 9 × ÷` ✅ | `4 5 6 + −` ✅ | `1 2 3` ✅
- `Ans` ✅ 上次结果 | `EE` ✅ 科学计数（×10ⁿ）| `xⁿ` ✅ 任意次幂（插入 `^`，右结合，指数可为完整表达式如 `2^(3+1)`）
- `0 .` ✅ | `=` ✅ 求值
- 上标第二功能：`%` 与 `e^x` ✅ 真做；其余字母 / F 系列 ⛔ 或作为变量名

### 符号约定
- 乘除显示为 `×` `÷`，内部求值转 `*` `/`。

## 5. 核心模块设计

### 5.1 编辑模型（tokens.js）
- 算式 = **token 数组** + **光标索引**。token 为语义单位：数字 `3.14`、运算符 `+`、函数 `sin(`、常量 `π`、变量 `A`、括号等。
- 数字键追加进当前数字 token；函数键插入 `sin(` 形式 token；`<` `>` 移动光标；`⌫` 删光标前一个 token；`AC` 清空。
- 每次改动后重渲染显示区，闪烁光标 `|` 画在对应位置。
- **undo/redo**：结构性改动前把 (token, 光标) 快照压入 undo 栈；`↶`/`↷` 回退/前进。

### 5.2 求值链（lexer → parser → evaluator）
- token 流 →**递归下降解析器**生成 AST。
- 优先级：函数/括号 > `^`（右结合）> 一元负号 > `× ÷` > `+ −`。
- **隐式乘法**：`2π`、`3(4)`、`2sin(30)` 自动补乘号。
- evaluator 遍历 AST：三角函数按当前 DEG/RAD 换算；`Ans` 取上次结果；变量从 STO 表读取；`EE` 即 `×10^`。

### 5.3 错误处理（方案 A）
- 解析失败 → `Syntax Error`；数学非法（除零、`√(-1)`、`Ln(0)`、`tan(90°)` 等）→ `Math Error`。
- 错误只显示在结果位置，**输入算式原样保留**，光标可继续编辑。

### 5.4 结果格式化（formatter.js）
- 内部用 JS `double`；显示前四舍五入到约 **12 位有效数字**，去除浮点毛刺（`0.1+0.2 → 0.3`）。
- 绝对值过大/过小自动切科学计数法（如 `1.23e15`）；否则常规十进制，去掉多余末尾零。

### 5.5 持久化（history.js + localStorage）
- 每次成功 `=` 存一条历史（算式 + 结果 + 时间戳）；历史面板点条目 → 把算式回填编辑区。
- STO 变量表（`{A: 值, B: 值, …}`）存 localStorage。二者关页面/重启后保留。

### 5.6 占位提示（toast）
- 点击任一 ⛔ 占位按钮时，弹出一个**短暂、非阻塞**的轻提示（toast），文案：**「该功能暂未开放」**。
- 约 1～1.5 秒后自动淡出消失；不打断当前算式编辑，不清空输入，不影响光标。
- 单一 toast 组件复用（连续点击时重置计时/覆盖上一条），避免堆叠。

## 6. PWA / 离线 / 部署

### 6.1 manifest.webmanifest
- 应用名、深色主题色、`display: standalone`（无地址栏，类原生）。
- `icons/` 提供 192×192 与 512×512。
- `start_url` 与 `scope` 用**相对路径**，适配 GitHub Pages 子路径。

### 6.2 sw.js（service worker）
- 安装时缓存全部静态资源（HTML/CSS/JS/图标）。
- **cache-first** 策略：离线直接读缓存，完全可用。
- 带版本号常量；升级改版本即让旧缓存失效。

### 6.3 视觉还原（styles.css）——按截图 1:1
- 上半：纯黑显示区，大号右对齐算式 + 闪烁光标；左上角 `DEG`/`RAD` 徽标（蓝/红配色同图）。
- 下半：按钮网格——功能行小字按钮 + 科学函数行 + 数字键盘区。数字键带浅灰立体块背景，第二功能上标用小号灰字标在键左上角。
- 配色：深黑底、白字、`Shift` 黄、`AC` 红、箭头蓝、`=` 独立高键。
- 响应式：移动竖屏为主，CSS Grid + `vh/vw` 自适应；桌面限制最大宽度居中（模拟手机比例）。
- 交互反馈：按钮按下轻微高亮；Shift 激活时相关键变色。

### 6.4 部署（README.md）
- 推到 GitHub 仓库 → Settings → Pages 选分支根目录 → 访问 `https://<用户名>.github.io/<仓库名>/`。
- 相对路径部署，子路径无需改配置。

## 7. 测试策略

核心引擎（lexer / parser / evaluator / formatter）为纯函数，编写用例覆盖：

- 运算符优先级与结合性（含 `^` 右结合、一元负号）
- 隐式乘法（`2π`、`3(4)`、`2sin(30)`）
- DEG/RAD 三角函数换算
- 错误分支（`Syntax Error` / `Math Error`）
- 浮点毛刺清理与科学计数法切换

可在浏览器控制台或简单 test 页运行。
